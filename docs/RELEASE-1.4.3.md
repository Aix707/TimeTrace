# TimeTrace 1.4.3

- 以 schema 7 为唯一数据基线，新数据库直接建立完整的表、字段、索引和默认提醒。
- 删除旧数据库格式的迁移分支、补列检测及迁移专用整理逻辑。
- 对其他版本或已有内容但未标记版本的数据文件，提示格式不受支持并保留原文件。
- 精简旧迁移测试，将验证工具整理为当前格式的数据完整性检查。
- 使用 schema 7 的历史记录、名称、主来源、合并关系及提醒配置继续保留。

旧格式数据可先通过 1.4.2 转为 schema 7，再升级本版本。[1.4.2](https://github.com/Aix707/TimeTrace/releases/tag/v1.4.2)

回归与发布核验结果见 [测试报告](TEST-REPORT.md)。
