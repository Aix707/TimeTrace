# TimeTrace 1.3.0

本版改进应用识别、记录归属和保存可靠性，沿用简洁的原生界面与基础功能。

## 更新内容

- 使用 Windows 应用标识、快捷方式、安装信息和程序元数据统一识别应用。证据充分时自动归组，手动名称和合并设置优先保留。
- 未识别记录集中显示为“未识别应用”。不足一秒的用时显示为“不足1秒”，原始毫秒记录完整保留，排行隐藏真正无用时的条目。
- 合并改为选择其他记录并入当前应用，保留当前应用身份，并沿用目标提醒配置优先的规则。
- 历史无用时日期仍保留所选应用的名称与操作。图标按可见条目加载，滚动时更新，关闭窗口后释放视图资源。
- 修复托盘悬停文字，启用 Windows 标准提示，并在任务栏重建后恢复当前暂停状态。
- 修复首次应用登记失败后的恢复，以及跨午夜保存失败重试时重复计时的问题。用时和提醒状态继续原子保存，退出时检查最终保存结果。

## 数据升级

首次运行自动将 schema 1—4 升级至 schema 5，保留原始使用区间、名称、手动分组及提醒配置。旧版分组的静默和剩余延后时间随规则迁移，已建立的应用组保持稳定。

证据不足的应用保留原有条目，可通过重命名和合并整理。已无法还原来源的历史未识别片段保留其用时。

## 运行与验证

继续使用 C++、Win32、系统绘图和静态 SQLite，保持单进程、一个工作线程及按需创建的界面。支持 Windows 11 x64，安装和运行均可离线完成。

本版资源、体积实测及尚待正式验收的项目见 [测试报告](TEST-REPORT.md)。
