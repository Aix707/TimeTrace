# TimeTrace 界面规范

1.1.4 沿用白底、胶囊导航和系统配色。应用详情的身份与管理栏移到底部；上方与概览共用同一统计布局，保持位置稳定。

## 三档字号

| 字号（DIP） | 用途 |
|---|---|
| 16 | 正文、状态、日期、图表坐标、按钮、编辑控件 |
| 22 | 页面与分组标题、应用详情名称、总时长单位 |
| 44 | 总时长数字 |

只用字重和颜色区分其余层级。文字格式共用缓存；窗口关闭时释放。使用 Microsoft YaHei UI／Segoe UI 与系统图标字体，没有下载或打包字体。Windows 管理的系统标题栏、确认／错误框与通知沿用系统字体设置。

## 共用尺寸

| 元素 | 尺寸（DIP） |
|---|---|
| 按钮、文字按钮、选项与输入框 | 高 36 |
| 常规／紧凑／时长／长文案操作 | 宽 120／80／160／216 |
| 图标 | 32 × 32 |
| 概览列表行 | 高 64 |
| 设置、提醒与详情提醒行 | 高 80 |
| 分组内边距 | 24 |
| 同排操作间距 | 12 |
| 控件／分组圆角 | 8／12 |
| 提醒与设置内容宽度 | 最大 820 |

尺寸集中在 `src/ui_metrics.h`。使用同一控制矩形和行文字方法：单行标签与控件垂直居中，两行标签与状态作为一组居中；操作右边缘与组内边距对齐。

## 页面与复用

- 概览：日期、总时长、趋势和应用排行。默认窗口显示四项应用，溢出数量在列表标题行显示，减少底部说明。
- 详情：底部同排显示返回、应用图标、名称、重命名和合并；日期、用时、趋势与概览位置相同。提醒位于统计区下方，今日状态独立于历史日期。
- 提醒：休息开关与间隔集中展示，应用列表保留名称、今日用时、每日时长和删除。点击时长直接修改，点击名称打开详情。
- 设置：常规、数据与隐私两组，移除重复说明；清除历史保留确认并默认取消。
- 复用：概览／详情共用完整统计布局，包括日期、图表和总时长的位置；详情／提醒页共用提醒行及延后／静默操作；设置与提醒共用行布局和尺寸。滚动与绘制共用可见行数计算参数。

默认窗口 1140 × 810，最小 920 × 680，按系统 DPI 缩放。长名称省略显示，长列表滚动。保留 Tab／Shift+Tab、Enter／空格、选项左右切换、Ctrl+1／2／3 与 Esc 返回。

## 文案与轻量实现

采用“今日用时”“本周用时”“今日已用”“未开启”“已暂停”等直接状态。列表和通知共用紧凑时长格式，整小时不写零分钟；删除不必要的说明句和宣传式空状态。

配色沿用白 #FFFFFF、正文 #1D1D1F、次要 #6E6E73、辅助 #86868B、蓝 #007AFF、绿 #34C759、红 #FF3B30，以及原有排行配色。只用细描边与短暂悬停／焦点反馈，无背景图片、模糊或常驻动画。

继续使用 Win32、Direct2D、DirectWrite、SQLite 与原有工作线程。没有网页容器、新后台线程或定时器；最小化时停止界面查询，关闭后释放绘图资源。统计计时和数据库结构保持不变。全部预览使用独立演示数据。
