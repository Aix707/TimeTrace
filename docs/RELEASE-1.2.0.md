# TimeTrace 1.2.0

- 提醒到期时才复制回滚状态，减少每秒心跳的分配与复制。
- 批量写入复用 SQL 语句，统一事务管理，缓存应用目录，简化周趋势聚合。
- 合并待处理的界面查询，以请求序号忽略旧快照；采集事件完整保留。
- 图标缓存包含失败结果，按当前视图保留最多 64 项；窗口关闭后释放工作线程缓存及整个界面快照。
- schema 4 移除两张废弃兼容表，当前使用记录和配置可以保留；首次升级仍可转换旧版限额。
- 统一版本来源，精简 SQLite 未用功能、重复图标提取与无用数据字段。

界面、计时口径、两种基础提醒与离线使用方式保持现有设计。此次未自动安装新版，也未清除真实数据；开发检查使用独立目录，数据升级仅在真实数据副本上验证。

安装包：`dist/TimeTrace-1.2.0-Setup.exe`。源码：`dist/TimeTrace-1.2.0-Source.zip`。实测与待验收项见 `TEST-REPORT.md`。
