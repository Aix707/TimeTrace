# TimeTrace 1.3.1

改进应用合并与成员管理。

- 合并窗口支持名称或程序路径搜索、多选及同目录记录优先显示。确认前展示目标应用、当前程序路径、选中数量和合并后用时。
- 应用详情显示合并成员，可查看各成员的名称、路径和所选时段用时，支持移出成员或设为主应用。
- 多项合并在一个事务内完成。移出和调整主应用保留原始时段，组提醒和剩余延后时间按新归属处理。
- 数据库升级至 schema 6，记住用户主动移出的成员，后续启动继续保持独立统计。

同目录信息辅助人工选择。已有独立产品和共享宿主的识别边界继续保留。

沿用 C++、Win32、系统控件和既有工作线程，新增界面按需创建。实测及验收范围见 [测试报告](TEST-REPORT.md)。
