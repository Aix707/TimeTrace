# TimeTrace 1.4.0

- 按识别出的应用名自动汇总，同名不同路径展示为一个应用。
- 分类由有使用记录的成员生成，应用选择器显示分类名称与用时。
- “设为主应用”同时切换名称和图标。每个来源保存自己的名称，切回后恢复。
- 重命名只保存到当前主来源。同名分类合并前预览合计用时并确认。
- 详情可查看来源名称、程序路径及用时，更改归属或独立为应用。
- 未识别用时单独汇总并计入总量。原始区间、手动归属和提醒状态在 schema 7 升级中保留。
- 保持原生界面、现有工作线程、一秒心跳与五秒批量保存。

本版检查及尚待正式验收的项目见 [测试报告](TEST-REPORT.md)。
