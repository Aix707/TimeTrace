# TimeTrace 1.4.2

优化后台工作与界面资源管理，修正来源管理和键盘操作中的问题。

- 前台识别按存活进程和有效应用标识复用结果，重复启动先完成单实例转交。
- 应用登记仅在元数据或归属实际变化时整理分类，批量写入复用事务内尾记录，提醒合并直接查询相关两项。
- 成员查询按日期索引汇总，仅期间无记录的成员查询历史存在性。
- 来源管理按需加载图标，程序路径变化后刷新，修复清空历史后的提醒图标显示。
- 画刷随绘图目标复用与释放，统一处理创建及绘制失败。
- 刷新后按控件角色、操作和应用恢复焦点，后台初始化错误可在重新打开窗口时查看。
- 主来源切换保留各成员原有的自动／手动标记，修复旧主来源切回及历史别名意外出现的问题。

数据库使用 schema 7，支持在原安装目录升级。安装器、便携程序、源码包和 SHA-256 校验文件随发行版提供。

本版回归测试与发布核验结果见 [测试报告](TEST-REPORT.md)。
